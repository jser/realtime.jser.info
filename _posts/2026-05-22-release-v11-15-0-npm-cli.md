npm CLI v11.15.0リリース。
Staged Publishingのための`npm stage`コマンドを追加、`trust`コマンドにpermissionsサポートを追加。
インストール時の挙動を制御する`allow-git`/`allow-file`/`allow-directory`/`allow-remote`の設定を追加。
