Node.js v24.0.0リリース。
V8 13.6へアップデート、npm 11を同梱、AsyncLocalStorageがAsyncContextFrameをデフォルトで使用するように。
`URLPattern`をグローバルに追加、パーミッションモデルが`--permission`フラグで利用できるように、テストランナーの改善、Undici 7を同梱。
`url.parse()`を非推奨に変更など。
2025年10月にLTSとなる予定。
