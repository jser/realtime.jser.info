Safari Technology Preview 247で追加されたSafari MCP serverについて。
AI AgentからSafariのタブを操作し、DOM/ネットワーク/コンソール/スクリーンショットを参照できる。
`safaridriver --mcp`で起動し、`navigate_to_url`/`evaluate_javascript`/`screenshot`などのツールを提供する。
