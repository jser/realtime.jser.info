GitHub Copilot SDKがテクニカルプレビューとして公開された。
Node.js/TypeScript、Python、Go、.NETの4つの言語で利用可能。
GitHub Copilot CLIへプログラムからアクセスするためのSDKで、マルチターン会話やカスタムツールの定義、クライアント/セッションのライフサイクル管理ができる。
