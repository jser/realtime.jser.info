Infernoの後継となるReactのHooksやSuspenseに近いモデルをコンパイルして動かすUIライブラリ。
Virtual DOMを使わず、TSX/TSRXをサポートし、Vite/Rspack/Rsbuild向けプラグインを提供する。
条件付きHooksや依存配列なしの`useEffect`、SSR/Streaming SSRなどに対応している。
