WebAssembly Specification 3.0リリース。
次の仕様が追加されている。

- 64-bit address space (memory64)  
- multiple memories  
- GC  
- typed references  
- tail calls  
- exception handling  
- relaxed SIMD  
- deterministic profile  
- annotation syntax  
- JS string builtins
